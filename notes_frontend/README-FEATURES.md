# Notes Frontend — Features

This Remix app implements a vintage notepad UI with:
- User authentication (demo cookie-based session; any email/password accepted)
- Notes CRUD (stored in localStorage per user)
- Search and filter by tags (top search bar + tag selection)
- Tag management (add/toggle tags)
- Responsive layout (top nav, sidebar on >= 900px, main editor)
- Minimalistic light theme closely matching the provided style guide

Run:
- npm install
- npm run dev

For production:
- npm run build
- npm start
